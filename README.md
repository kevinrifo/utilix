# UtiliX

UtiliX is a fast, simple, and accessible collection of free online tools designed to make everyday digital tasks easier.

## Current status

The project is being scaffolded with a UI-first approach. Tool screens are available as navigable placeholders; processing logic will be added later.

Planned tools:

- PDF Compressor
- Audio Converter
- Video Downloader

## Tech stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Redux Toolkit + React Redux
- React Router 8

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Scripts

| Script              | Description                         |
| ------------------- | ----------------------------------- |
| `npm run dev`       | Start the Vite development server   |
| `npm run typecheck` | Run TypeScript checks               |
| `npm run build`     | Typecheck and create a production build |
| `npm run preview`   | Preview the production build        |
